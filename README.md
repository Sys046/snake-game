# 贪吃蛇 · Snake

一个单文件 HTML5 贪吃蛇小游戏，打开即玩，无需安装、无需构建。

## 在线玩

https://sys046.github.io/snake-game/

## 玩法

- **电脑**：方向键 或 `WASD` 转向，`空格` 暂停/继续
- **手机**：在棋盘上滑动，或使用下方虚拟方向键
- 吃到红色方块 **+10 分**，速度会逐渐加快
- 撞墙或咬到自己即结束，最高分自动保存在本地浏览器

## 特点

- 单文件，零依赖，纯 Canvas 实现
- 响应式布局，手机/电脑通用
- 支持键盘、滑动、虚拟按键三种操作
- 深色霓虹风格，带最高分记录

## 本地运行

直接用浏览器打开 `index.html` 即可；也可以起一个静态服务器：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```
